# Data Agency Website

A responsive landing page for **Data Agency**, showcasing services in **AI, Data Analytics, Business Intelligence, and Cloud Solutions**. Built using **HTML, CSS, Bootstrap 5, and JavaScript**.

---

## 🖥 Project Overview

This website demonstrates the agency’s offerings with:

- Hero section with a banner image and call-to-action buttons.
- Services section highlighting key solutions.
- About section explaining the company and team.
- Pricing plans with toggle between monthly/yearly options.
- FAQ accordion for common questions.
- Testimonials carousel.
- Contact form with modern design.
- Responsive layout for desktop, tablet, and mobile devices.

---

## 🔧 Technologies Used

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **JavaScript**
- **FontAwesome**
- **Google Fonts (Poppins)**
